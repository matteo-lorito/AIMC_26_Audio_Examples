This repository includes audio examples of double-bass and autonomous Rhuthmic sytem co-improvisation

The double bass tracks are prerecorded, so no real interaction is in act here, besides the one exerted from the co-improvisor interacting with the audio track.
Two different audio track are used.

The sound generator interfaced with the rhythm-generator system is:
For examples 1, 2, 3, 5 a synthesizer coupled with a random note generator;
For examples 4, 6 with the timbral navigation system;
